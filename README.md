# 爱在ZJU · 团队产品与交付包

当前网站、五种可交付产品的源码、插画/音频/字体素材，以及按订单生成离线成品的工具。基于 2026-10-29 本地生产源整理。

## 组员先做这三步

1. 克隆仓库或下载 ZIP，安装 Python 3.10 及以上版本。没有第三方 Python 依赖。
2. 在仓库目录运行 `python tools/preview.py`，打开终端显示的本地地址，即可浏览全部产品。
3. 复制对应的 `examples/*.json` 到 `orders/订单编号/order.json`，填入客户确认过的文字，执行：

```powershell
python tools/build_gift.py orders/AZ-DEMO/order.json
```

成品位于 `deliveries/订单编号/打开礼物.html`，同时生成 `deliveries/订单编号.zip`。HTML 已嵌入所需样式、脚本、照片和音频，下载后可以离线打开。先自己验收，再将 ZIP 私下发给客户。

新手可以先运行示例：

```powershell
python tools/build_gift.py examples/birthday.json
```

Windows 也可以双击 `预览网站.cmd`；各产品的快速生成命令见 [产品与字段](docs/产品与字段.md)。若电脑上使用 `py` 命令，以上命令中的 `python` 换成 `py -3` 即可。

## 文件放在哪里

| 目录 | 用途 |
| --- | --- |
| `site/` | 门户、产品样片、定制表单及管理页的静态源码 |
| `site/assets/` | 插画、照片示意、原创演示音频、样式、脚本、花体字体与授权说明 |
| `examples/` | 纯虚构的五种产品配置示例 |
| `产品体验包.zip` | 五类已导出的离线示例，解压即可体验 |
| `materials/concepts/` | 最初的门户、分类、回忆、唱片效果图，含旧品牌，仅供设计参考 |
| `tools/` | 本地预览与离线成品生成工具 |
| `docs/` | 产品边界、协作流程、部署和运营说明 |
| `server/` | 收单函数及测试，仅负责人部署时需要 |
| `orders/` | 每位组员本机上的客户材料，不提交 GitHub |
| `deliveries/` | 本机生成的客户成品，不提交 GitHub |

**组员生产礼物不需要开通阿里云、复制邮箱授权码或部署收单后台。** 收单和核款仍在现有官网统一完成，负责人把已确认订单分配给组员。仓库中的收单接口默认留空，避免本地演示误写入生产订单。

浏览器里“写下心意”的修改只用于临时预览；需要交付时，必须写入订单 JSON 并重新生成 HTML。不要把修改过的浏览器标签页当成已保存的成品。

## 如何一起工作

负责人核款 → 确认产品范围/档期 → 分配一位制作人 → 制作人填配置并生成 → 另一位组员验收 → 私下交付客户。每单只设一位负责人，避免重复制作。

客户信息通过私有渠道点对点分配，不写进 GitHub Issue、PR、提交信息或示例配置。代码改进使用独立分支和 PR；所有人从主分支拉取产品模板，客户的个性化内容保留在各自被忽略的订单目录。

详见 [团队交付流程](docs/团队交付流程.md)、[部署与后台](docs/部署与后台.md) 和 [素材说明](docs/素材说明.md)。
