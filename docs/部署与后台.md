# 本地使用、团队部署与生产后台

## 组员生产礼物

只需 Python 3.10+ 和浏览器，不必安装 npm、不需要数据库或阿里云账号。`python tools/preview.py` 在 127.0.0.1:8080 提供站点预览；直接双击 `site/index.html` 也能浏览大部分样片。

对客户的交付用 `tools/build_gift.py` 输出的离线 HTML / ZIP。浏览器临时编辑、blob图片地址和打开中的标签页均不构成可交付文件。

## 想让组员有自己的演示网址

静态目录是 `site/`，可部署到支持 HTTPS 静态文件的网站托管。所有链接采用相对路径。先检查托管服务在目标校园网络/手机上能否访问，再对外分享。私有 GitHub 仓库的代码访问权限和托管页面可见性是两回事，需要分别确认。

本团队包的 `site/assets/intake-config.js` 默认 endpoint 为空，演示不会向官网创建订单。不要将自己的预览地址设成生产收单入口。修改该文件并不会自动部署后台或开通支付权限。

## 生产负责人维护收单后台

`server/main.py` 是现有 FC 处理器源码，Python 3.12，入口 main.handler。依赖运行时内置的 oss2；迁移到其他运行时要另行安装。`test_service.py` 可以在本地通过 `python -m unittest discover -s server -p test_service.py` 运行。

本包没有生产凭据、客户订单或证书私钥，也没有自动创建付费资源的脚本。生产需要独立配置香港私有 OSS 订单桶、函数角色最小权限、HTTPS 域名、匿名HTTP入口及环境变量。环境变量名见 `server/.env.example`；不要将真实值写入代码或提交仓库。

保持单实例并发1、最大实例1，当前简单JSON读改写模型不适用于放宽并发。订单接口需要浏览器CORS配置；网站Origin允许列表和API域名一起核对。个人收款码只能人工核款；不能靠前端按钮把订单标成已验证到账。

邮件失败仍保留订单。内部定时任务 payload 为 `{"job":"retry_notifications"}`，试运行使用每4小时一次，失败最多8次后人工处理。单次重试最多2封。SMTP接受不等于收件箱必达，且不能保证严格只发一次。

管理API要求 Bearer 管理密钥。公开静态桶只能存网页素材，订单桶必须私有且阻止公开访问。保持订单数限流；限流和预算告警都不等于云费硬上限。2026-10-28 曾因云账号欠费导致接口403，补足余额后恢复，遇到提交失败需检查实际HTTP响应及云端状态。

现有生产网站：https://www.loveinzju.top/ 。网站及API证书需负责人手动续期，已知到期日分别为2027-01-24、2027-01-26；部署配置与证书状态应在实际维护时重新核实。
