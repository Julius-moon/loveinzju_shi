# 产品与字段

首月体验价以当前官网有效活动为准；这些示例不执行收费，不能作为核款凭证。图片、音频或布局升级先确认范围和报价。生成器支持素材替换，是内部制作能力，不代表基本价包含这些服务。

| 产品 / product | 基本价 | JSON主要字段 | 当前模板边界 |
| --- | --- | --- | --- |
| 星空生日 / birthday | 9.9 | name、birthday、messageCN、hiddenWish；messageEN可选 | 沿用现有蛋糕、星空和动画 |
| 我们的N个瞬间 / memory | 19.9 | names、quote、moments | 当前画布固定5个位置；少于5段时先和客户确认补齐方式，不编造故事 |
| 送你一张唱片 / record | 15.9 | recipient、sender、date、track、message | 基本款用现有封面/演示曲；cover和audio是另议选项 |
| 青春有迹可循 / campus | 29.9 | title、years、places | 3—5个地点，沿用虚构示意地图；不承诺真实地理导航 |
| 大家的悄悄话 / letters | 29.9 | recipient、intro、letters | 1—5封信；署名、标题、正文和隐藏语分别填写 |
| 草莓生日 / strawberry | 9.9拟定 | 暂无可交付模板 | 筹备中，只接受询问，不能直接制作 |

所有配置都有 `order_id` 和 `product`。订单编号只允许字母、数字、短横线和下划线，不使用客户姓名做路径。

回忆 `moments` 每项需要 `caption`、`date`、`text`、`secret`；校园 `places` 每项需要 `title`、`date`、`text`、`secret`；信件 `letters` 每项需要 `from`、`title`、`body`、`secret`。隐藏文字可填空字符串。

可选图片字段 `image`、唱片封面 `cover` 及音频 `audio` 填订单目录内的相对文件路径，如 `photos/01.jpg`、`song.mp3`。图片支持 JPG/PNG/WebP、每张不超过10MB；音频支持MP3/WAV/M4A/OGG、不超过20MB，最终可播放性仍需浏览器实测。未经客户授权，不获取音乐平台曲目作为交付素材。

```powershell
python tools/build_gift.py examples/birthday.json
python tools/build_gift.py examples/memory.json
python tools/build_gift.py examples/record.json
python tools/build_gift.py examples/campus.json
python tools/build_gift.py examples/letters.json
```

配置是 UTF-8 JSON：字符串用双引号，行尾不要留多余逗号。需要改版式或效果时修改 `site/` 中对应 HTML、assets 下同名JS/CSS，先运行示例生成并验收，再提交模板改动。
