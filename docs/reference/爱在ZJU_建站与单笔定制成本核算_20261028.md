## 经营判断与执行

9.9元生日可以作为入口款，前提是总交付工时稳定在10分钟左右。20分钟生日人工已10元，售价不足覆盖人工，不能用软件成本近乎零解释盈利。其余品类也要靠固定模板和素材规范。

生日基准贡献4.15元意味着在不扣固定摊销时，每获得一笔实际付款的获客成本也必须低于4.15元才有正余量。按每月100单且Plus全部分摊，生日只余约2.71元覆盖进一步获客与其他费用，不能承受5元/单推广成本。免费发帖同样消耗劳动。

建议首轮每款做3次完整模拟单，记录收料、确认、替换、检查、交付、修改的实际分钟；再用前10笔真实订单替换模型。内容出错返工、未成交咨询与退款单不应从工时样本里删掉。采用中位数和较慢订单工时核价，不按最快一单宣传。

本账仍缺实际OSS账单、Plus银行实扣与额外额度购买记录、团队真实工时、实际支付费率、投放支出与交付测试记录。没有这几项，就只能形成透明的成本模型，不能出具精确历史总账。
