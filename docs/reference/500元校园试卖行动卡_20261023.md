# 留一份 · 500元校园试卖行动卡

日期：2026年10月23日。以下是首轮试卖方案，报价、工时和通过线均为经营假设，尚未被付款验证。本轮不改网页报价、不发布广告、不联系客户。

## 先卖给谁

主客群：未来30天内，想给朋友、恋人或室友送礼的在校生。优先找已有照片、有送出日期、自己可以决定付款的人。

次客群：宿舍、朋友小队、社团成员自发合购，由一个联系人收齐材料、确认作品并付款。正式组织采购、需要报销或发票的订单，在开票路径确认前先不承诺接单。

不因为暂不能自开发票就排除所有多人场景。浙江税务公开指南提供符合条件的个人申请代开发票路径，但你是否适用、材料与税费如何处理仍需具体核实。降价不能解决报销手续问题。

来源：[浙江税务2026年4月8日办税指南](https://zhejiang.chinatax.gov.cn/art/2026/4/8/art_26347_652752.html)，本轮已读取；不据此承诺本人已具备开票条件。

## 四步执行

**第1至2天，打通交付。** 用一份虚构测试订单从收料做到交付。当前编辑功能只在当前页面生效，须补齐客户内容的保存与独立成品导出。成品应在第二台设备重新打开，姓名、文字、图片和音频一致；手机端打开方式确认后再承诺手机交付。过程中生成配置表、成品文件和验收记录。

**第3至5天，找第一批具体任务。** 准备生日、回忆两条15至20秒真实操作录屏。自有朋友圈先展示，在管理员允许的校园群及CC98／朵朵适用入口发一份真实报价。目标是接触约20位有近期送礼日期、看过价格的潜客，不群发陌生私信，不送免费作品换点赞。

**第6至10天，交付前5单。** 先确认范围、日期和打开设备，再收材料与款项；对首次购买者先展示完整样片和文字约定。执行建议：素材齐全后48小时交付，先用样单验证是否做得到；单人同一天最多接3单，不承诺无限急单。错误、延期和取消的处理在制作前说明，未开始制作的取消全退，未按约完成的订单负责补救或退款。

**第11至14天，复盘后再花钱。** 分别统计真实全款订单、退款、熟人支持单；记录每单收入、现金成本、总耗时、来源以及是否实际送出。若有5笔真实需求付款，其中至少3笔来自非支持性购买，且作品能按时打开、工时大致可控，再做下一批10单。若20位明确看过报价的合格潜客只有0至1人购买，先调整一次样品或定位，再测试一批；不直接加投广告。
